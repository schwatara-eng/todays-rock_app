# 🎸 오늘의 록 — TODAY'S ROCK

> 오늘의 날씨와 지금 내 기분에 맞는 세 곡, 그리고 음악을 더 깊이 만나는 뉴스와 뮤지션 이야기.

**[👉 서비스 바로가기](https://today-rockapp.vercel.app/)**

## 소개

「오늘의 록」은 현재 위치의 **날씨**와 사용자가 선택한 **기분**을 조합해, **500곡의 록 음악 데이터**에서 오늘 듣기 좋은 세 곡을 추천하는 웹 애플리케이션입니다.

곡마다 주제·정서와 분위기·추천 이유를 함께 보여주고 YouTube와 가사 페이지로 연결합니다. NME 음악 뉴스와 ‘오늘의 뮤지션’ 콘텐츠를 더해 음악 감상과 읽을거리를 한 화면에서 제공합니다.

- 제작: 2026.10
- 수업: AI 데이터 저널리즘
- 문서 기준: 2026.10.13 저장소 코드

### 날씨 조회 실패 시

위치 권한을 허용하지 않거나 위치·날씨 조회에 실패하면 서울 날씨로 다시 조회합니다. 서울 날씨도 가져오지 못하면 ‘흐린 날’을 기준으로 추천합니다.

## 추천 방식

현재 추천은 **JSON 태그 기반의 우선순위 선택과 무작위 추출** 방식입니다. 실행 시 AI 모델이나 외부 음악 API를 호출하지 않습니다.

기분을 선택한 경우 다음 순서로 세 곡을 구성합니다.

1. 최근 추천한 곡을 제외하고, **기분과 날씨가 모두 일치**하는 곡에서 무작위 추출
2. 세 곡이 부족하면 **기분이 일치**하는 미추천 곡으로 보충
3. 그래도 부족하면 최근 추천했던 기분 일치 곡도 허용
4. 기분에 해당하는 곡 자체가 부족하면 전체 곡에서 보충

기분을 선택하지 않으면 최근 추천곡을 제외한 전체 곡에서 세 곡을 무작위로 고릅니다. 남은 후보가 세 곡 미만이면 전체 곡을 다시 사용합니다.

- 날씨 태그: `clear` · `cloudy` · `rain` · `snow`
- 최근 추천 기록: 같은 브라우저의 LocalStorage에 최대 30곡 저장
- 기록 식별 기준: 아티스트명 + 곡명
- 에너지 지수: 카드에 표시되는 정보이며 현재 추천 점수에는 사용하지 않음
- 오늘의 원픽: 세 곡 중 첫 곡이며, 별도의 점수 평가로 선정하지 않음

## 곡 데이터

`data.json`에 **500개 곡 항목**을 저장합니다. 현재 데이터의 발매 연도 범위는 **1963~2024년**입니다.

별도의 MySQL 데이터베이스 없이 브라우저가 JSON 파일을 불러와 추천합니다.

```json
{
  "title": "Don't Look Back in Anger",
  "artist": "Oasis",
  "year": 1995,
  "genre": "Britpop",
  "moods": ["blue", "frustrated"],
  "weathers": ["cloudy", "rain"],
  "energy": 3,
  "theme": "후회와 분노를 지나 과거를 놓아주는 태도",
  "tone": "쓸쓸하게 시작해 거대한 합창으로 벅차오르는 분위기",
  "reason": "천천히 고조되는 합창이 복잡한 마음을 바깥으로 밀어냅니다.",
  "lyricsUrl": "https://genius.com/Oasis-dont-look-back-in-anger-lyrics"
}
```

| 필드 | 용도 |
| --- | --- |
| `title` / `artist` | 곡명 / 아티스트명 |
| `year` / `genre` | 발매 연도 / 장르 |
| `moods` | `tired`, `calm`, `blue`, `excited`, `frustrated`, `focused` 중 하나 이상 |
| `weathers` | `clear`, `cloudy`, `rain`, `snow` 중 하나 이상 |
| `energy` | 에너지 지수, 1~5 |
| `theme` / `tone` / `reason` | 곡의 주제 / 정서·분위기 / 추천 이유 |
| `lyricsUrl` | 외부 가사 페이지 주소 |

곡 추가·수정은 같은 형식으로 `data.json`을 편집하면 됩니다. 주제·분위기·추천 이유는 데이터에 미리 작성된 해설을 표시합니다.

## 오늘의 뉴스

브라우저가 `/api/news`에 요청하면 Vercel 서버리스 함수가 NME RSS를 수집하고 JSON으로 반환합니다.

- 수집원: [NME Music News RSS](https://www.nme.com/news/music/feed)
- 수집 범위: 음악 뉴스 피드의 최신 3개 기사 — 록 장르만 별도로 필터링하지 않음
- 처리: RSS XML 파싱 → HTML 태그 제거 → 설명 최대 160자 추출 → 영어에서 한국어로 번역
- 번역: 제목 3개와 설명 3개를 한 번에 요청
- 화면: 기사 3개의 제목·날짜·원문 링크, 첫 기사의 설명 표시
- 번역 키가 없거나 번역에 실패하면 영문 원문 유지
- 캐시: CDN 캐시 1시간, 재검증 중 기존 응답 제공 허용 시간 24시간
- 뉴스 수집 실패 시 뉴스 영역에 오류 안내 표시

번역 대상은 RSS의 제목과 설명이며 기사 전문은 NME 원문 링크에서 확인합니다.

## 로컬 실행

### 화면과 추천 기능 확인

`data.json`을 `fetch`로 불러오므로 HTML 파일을 더블클릭하는 대신 로컬 서버를 사용합니다.

```bash
git clone https://github.com/schwatara-eng/todays-rock_app.git
cd todays-rock_app
npx serve .
```

또는 VS Code에서 `index.html`을 우클릭한 뒤 **Open with Live Server**를 선택합니다.

정적 서버만 실행하면 `/api/news`가 처리되지 않아 뉴스는 표시되지 않습니다.

### 뉴스 API까지 함께 확인

Node.js와 npm이 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```bash
npm install
npx vercel dev
```

처음 실행할 때 Vercel 로그인과 프로젝트 연결이 필요할 수 있습니다. 터미널에 표시된 로컬 주소로 접속합니다.

한국어 번역을 사용하려면 실행 환경에 아래 변수를 설정해야 합니다.

| 환경 변수 | 용도 |
| --- | --- |
| `GOOGLE_TRANSLATE_API_KEY` | Google Cloud Translation API 키 |

키를 설정하지 않으면 뉴스는 영어로 반환됩니다. API 키는 프런트엔드 코드나 저장소에 작성하지 않고 서버 환경 변수로 관리합니다.

`node server.js`는 `http://localhost:3000/api/news`에서 RSS 수집만 확인하는 별도 테스트 서버입니다. 웹페이지를 제공하지 않으며 번역 기능도 포함하지 않습니다.

## 배포

Vercel에서 정적 프런트엔드와 `api/news.js` 서버리스 함수를 함께 제공합니다.

1. GitHub 저장소를 Vercel 프로젝트에 연결합니다.
2. Vercel 프로젝트 환경 변수에 `GOOGLE_TRANSLATE_API_KEY`를 등록합니다.
3. 환경 변수 변경 후 다시 배포합니다.
4. 배포 주소에서 추천 기능과 `/api/news` 응답을 확인합니다.
